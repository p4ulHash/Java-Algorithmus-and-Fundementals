# ? Java Algorithms & Fundamentals

> A curated collection of fundamental programming exercises and basic data handling scripts implemented in Java.

## ? About The Project
This repository serves as a centralized collection of foundational university assignments. It demonstrates core programming concepts, control flow logic, and low-level data structuring without relying on advanced external libraries.

### ? Included Modules & Contents
* **Loops (`02-Loops`):** Implementation of precise custom number sequences (such as step loops and powers of 2) and iterative numerical approximation using Heron's method for calculating square roots[cite: 4].
* **Arrays (`02-Arrays`):** Fundamental array manipulation algorithms including mathematical aggregations (sum and mean), vector addition, element sorting checks, and array slicing (`tail`)[cite: 4].
* **Caesar Cipher (`03-CaesarChiffre`):** A cryptography console application that encrypts and decrypts text. It utilizes character arrays and ASCII shifts, and implements statistical frequency analysis (histograms) to automatically crack ciphers based on language patterns[cite: 8].

## ?? Built With
* **Language:** Java
* **IDE:** IntelliJ IDEA
* **Core Concepts:** Control Structures, Iterative Algorithms, Array Manipulation, Basic Cryptography & Data Analysis
